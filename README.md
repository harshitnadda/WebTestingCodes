# WebTestingCodes

## FetchWebPage
You can fetch a webpage by changing the URL.  
If it is getting fetched, then it can be loaded on a page and may be used in phishing scenarios or as an XSS payload.

## test.js
This script is an example payload that can be used for XSS testing.  
If it gets loaded successfully, then the website may be vulnerable to XSS through loading external payloads.

> Note: jQuery should already be present on the website for this to work successfully.
